# Nitrosend CLI — first send

Report and evidence for a first transactional send made with the published
`@nitrosend/cli`, written as part of a Nitrosend OSS dogfood round.

- `report.md` — what was installed and run, timings, the slowest step, one
  defect with an exact repro, and one suggested change.
- `evidence.json` — the measured observations behind the report, each with the
  command that produced it and the actual response.
